Add `OkklyTextField` (`okkly-text-field`), a single-line text input with label, helper, and error — the foundation for most form fields. Built on a new internal `Field` shell shared with future field-based controls (Select, Autocomplete). `color` supports every design-system accent token (`primary`, `secondary`, `dante`, `violet`, `ember`, `ice`, `contrast`).
